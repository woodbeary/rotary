# Backlog Canonicalization Comment Templates

Use these templates for issue closure and status snapshot comments to keep decisions auditable and consistent.

## Closure Template

```md
Decision: CLOSE
Reason: <duplicate|superseded|noise|completed-with-proof>
Superseded by: <#issue-number or N/A>
Evidence links:
- <link or path>
- <link or path>
Date: <YYYY-MM-DD>
```

## Status Snapshot Template

```md
State: <active|blocked|needs-proof>
Next action: <single next action>
Owner: <engineering|ops|product>
Blocking dependency: <dependency or none>
Date: <YYYY-MM-DD>
```
